# SEO 外链平台清单（可发布渠道与操作口径）

> **用途**：站点做外链建设时的执行清单——按「可发布位置 / 留链方式 / 注意事项」逐条落地。
> **适用对象**：`{DEPLOY_DOMAIN}` 官网及其站内落地页。
> **配套**：落地页对照见 [第六章](#六落地页对照表)，关键词规划与站内 SEO 基线见 [变更记录.md](变更记录.md) 中「SEO 基线」条目。

> ⚠️ **声明**：各平台的**外链政策、审核尺度与收录表现会随时调整**，本清单只给渠道与操作口径，不保证某平台在某一时刻仍允许留链。
> **发布前必须先看该平台当时的版规 / 社区规范**，被删帖、被降权、被封号的代价远大于一条外链的收益。
> ⚠️ 本文档遵守 [README.md](README.md) 维护约定：不写真实域名与服务器信息，统一用 `{DEPLOY_DOMAIN}` 占位。

---

## 一、执行前先确认三件事

1. **承接页要选对**：本站真正的 SEO 承接页是 `/docs/<服务>/`（一服务一页，声明数据见 `../API/website/docs/`）。外链应指向**最相关的服务页**，全部指向首页是浪费。
2. **锚文本要分散**：以长尾服务词为主（「抖音视频解析API」「免费代理IP接口」…），品牌词「小影API」占比控制在 **30% 以内**；同一篇文章只放 **1–2 个链接**。
3. **先补站内再发外链**：站内基线（`/sitemap.xml`、`/robots.txt`、各服务页正文与关键词）已完成；外链只是放大器，承接页没内容时外链几乎无效。

### P1 · 站长平台与目录 / 导航站（基础收录）

| 平台 | 作用 | 操作 | 注意事项 |
| --- | --- | --- | --- |
| 百度站长平台 | 提交站点、加速收录 | 提交 `{DEPLOY_DOMAIN}/sitemap.xml`；用「普通收录 → 主动推送」推单个 URL | 页面已有百度验证 meta，直接登录即可绑定；新站**主动推送对收录速度影响比外链更直接** |
| Google Search Console | 提交 sitemap、看收录 | 提交 `{DEPLOY_DOMAIN}/sitemap.xml` | 若做英文/海外流量必做 |
| Bing / IndexNow | 提交收录 | 提交 sitemap 或调用 IndexNow | 成本低，顺手做 |
| 程序员导航 / API 导航 / 工具导航类目录站 | 目录型外链 | 按各站投稿入口提交 | 锚文本用长尾服务词；**只提交能打开的站**，被拒就换一家 |
| 站长之家 / 爱站 等站长工具站 | 收录查询与提交 | 按各站提供的入口提交 | 以能实际带来蜘蛛抓取为准，不必强求 |

> 目录站数量多但质量参差，**优先挑与「开发者工具 / API」主题相关的**；批量提交无关目录站意义有限。

### P1 · 问答与社区（需谨慎，先给价值再提链接）

| 平台 | 可发布位置 | 留链方式 | 注意事项 |
| --- | --- | --- | --- |
| 知乎 | 回答 / 文章 | 正文引用资料 | 外链会弹跳转提示；**先答问题本身**，把链接当作补充资料，硬广会被踩与折叠 |
| V2EX | 「分享创造」等节点 | 正文引用 | 明确「我做了个 X」的场景较受欢迎；纯推广贴会被喷，且社区反感 SEO 行为 |

| 平台 | 用途 | 注意事项 |
| --- | --- | --- |

| B 站 / 抖音 | 录屏演示「用它做了个什么」 | 简介与置顶评论放地址；适合建立认知，不是外链 |

### 友链互换（最自然的互惠外链）

本站已内置友链能力（`/api/seo/friend_links`，前端页脚展示启用项），可直接用它管理互换结果：

1. 找**内容相关、量级相近**的开发者站 / 工具站 / API 聚合站；
2. 通过站内联系方式（页脚微信 / Telegram）沟通互换；
3. 交换后用 `/api/seo/friend_links` 的创建接口登记，启用后自动出现在页脚。

**避免**：与内容无关的博彩、灰色、纯采集站换链——这类友链会拖累整个域名。

## 三、一条内容的多平台分发口径

同一条内容不要在同一时间全平台一字不差地复制，容易判定为低质采集。建议：

| 顺序 | 动作 | 说明 |
| --- | --- | --- |
| 1 | 站内先落一份完整文档 | `/docs/<服务>/`（正文区已具备），作为「唯一权威来源」 |
| 2 | 首发一个主平台 | 掘金或 CSDN 选一个，作为原创首发 |
| 3 | 间隔 1–3 天二次分发 | 换标题切片、补不同示例，发到另外 1–2 个平台并注明来源 |
| 4 | 择机做问答型内容 | 在知乎 / 思否回答「怎么实现 X」，正文自然引用文档页 |
| 5 | 沉淀成代码 | 把文中示例整理成 SDK / 示例仓库放到 GitHub / Gitee |

**节奏建议**：每周 1–2 篇即可，**稳定持续**比一次性铺量更有效；同一篇不要短时间内在 5 个以上平台重复。

## 四、不要做的（风控红线）

- ❌ **购买外链 / 链接包**：性价比极低，且可能被判作弊导致整站降权。
- ❌ **批量论坛签名、博客评论刷链**：2026 年的搜索引擎对此基本免疫，甚至反噬。
- ❌ **站群互链、隐藏链接、蜘蛛池**：明确作弊手段，一旦命中就是整站级处罚。
- ❌ **在问答平台硬广**：账号被封的损失远大于一条外链，且会毁掉后续渠道。
- ❌ **让全部外链锚文本都写「小影API」**：锚文本过度集中是典型作弊特征。

## 七、效果回收

- **收录**：百度站长「普通收录」看提交与索引量；Search Console 看已编入索引数。**收录未起来前，先查承接页是否可正常访问、是否被 `robots.txt` 误挡**。
- **流量**：区分「直接访问」与「自然搜索」，前者多为社区引流，后者才是 SEO 成果。
- **转化**：本站已按天统计调用量（超管看板 `/console/stats/`，公开口径 `/api/statistics/`）。外链带来的注册与调用增长，比排名本身更能说明问题。
- **判断周期**：外链与收录都有滞后，**至少观察 2–4 周**再判断某个渠道是否值得继续投入。

## 八、内容边界与风险提示（重要）

本站部分内容属于**风控规避 / 灰产边缘**范畴（斗篷、反调试、评论自动发布、代练等），这部分：

- 在百度/搜狗容易被**整站降权**（「斗篷」这类词本身就是明确的作弊信号）；
- 发到正规平台容易**违规封号**，反过来毁掉账号资产。

**结论**：外链与对外内容推广**只押合规且有真实搜索需求的栏目**（电影、代理IP、验证码识别、音乐、邮箱/临时邮箱、图床、AI、用户中心等）；风控类内容只做站内，不主动对外发外链、不与主域名强绑定。
