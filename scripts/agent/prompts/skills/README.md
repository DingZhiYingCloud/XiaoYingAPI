# 技能目录

把 `*.md` 文件丢进这个目录，它的内容会被**原样追加到大脑的系统提示词**最后，
相当于给大脑补一段“背景知识 / 规范 / 偏好”。

适合放的东西，例如：

- 你们服务器清单与用途（哪台跑什么业务、什么不能动）
- 运维规范（“改配置必须先备份”“重启服务只能选低峰期”）
- 常见故障的处理套路（“502 先看 nginx 错误日志，再查 upstream”）
- 术语翻译（把业务黑话翻译成服务器动作）

## 怎么写

每个文件自己写标题，内容用大白话即可，例如：

```markdown
## 我们公司的服务器

- server-1：主站（nginx + uwsgi），**不能随便重启**
- server-2：数据库，改动前一定先备份
- server-3：测试机，随便折腾
```

## 注意事项

- 本文件（README.md）不会被加载，只是说明。
- 同名文件里，`~/.ai-brain/prompts/skills/` 里的会覆盖程序自带的。
- 加太多会让提示词变长、变贵，建议精简。
