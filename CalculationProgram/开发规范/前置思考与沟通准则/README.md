# 前置思考与沟通准则

> **是什么**：一套给 AI 协作者 / 开发者用的「先想清再动手」准则，覆盖前置思考、极简设计、精准修改、目标驱动、交付质量、环境隔离、复用一致七部分。
> **特点**：只约束判断原则，不写死目录名、阈值与工具；可变项一律交给项目约定，因此可以直接复用到不同项目。

## 文件

| 文件 | 说明 |
| --- | --- |
| `前置思考与沟通准则.md` | 完整正文（可在线预览 / 下载） |

## 怎么用

- 直接作为团队 / 个人的协作约定；
- 放进 AI 工具的项目规则（如 `.trae/rules/`、`AGENTS.md` 或等效规则文件）；
- 项目有自定义目录 / 阈值 / 工具链时，在项目内单独维护「参数约定」，本文保持通用；
- 需要逐条对照执行时，按正文的一至七节顺序阅读即可。

## 适用提示

- 文中出现的 `.venv`、行数等只是示例，项目有自己的约定时以项目约定为准；
- 第六节的虚拟环境要求同样适用于 conda / poetry / uv / Docker 等其它隔离方式；
- 本文与具体 AI 工具无关，可整体或分段引用。
