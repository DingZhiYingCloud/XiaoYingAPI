# 前端开发必看（强制使用 daisyUI）

> **优先级最高的前端约束文档。** 任何 AI / 开发者编写、修改本项目 `API/templates/` 下的 Django 模板、HTML、前端页面之前，**必须先读完本文档**，并**必须调用 daisyui skill**（位于 `.trae/skills/daisyui/SKILL.md`，与系统全局 daisyui skill 同源）。本文档内容与 skill 冲突时，**以本文档为准**。
>
> **动手前强制自检（不得跳过）**：写任何模板代码之前，先确认本机具备第 5.0 节的编译产物；**只要缺任意一项，就必须先按第 5 节自动补齐并编译出 `output.css`，再开始写页面**。缺产物时页面会完全无样式，写了也无法验证。检测到缺失可直接执行安装命令，**无需再询问用户**。

## 1. 为什么必须用 daisyUI

本项目前端已统一接入 **daisyUI 5**（基于 **Tailwind CSS 4**），并提供语义化组件类与多主题（明/暗），无需再引入任何其它 UI 框架或手写大量样式。

**禁止事项（AI 硬性红线）：**

1. 禁止引入 Bootstrap、Element UI、Ant Design、layui 等其它 UI 库 / CSS 框架。
2. 禁止新增全局 CSS 覆盖 daisyUI 组件外观（如重写 `.btn`、`.card`）。个别特殊样式用 Tailwind 工具类在元素上组合实现。
3. 禁止在页面硬编码颜色/圆角/阴影数值（如 `color:#1677ff`）。统一使用 daisyUI 语义类（`text-primary`、`bg-base-100`、`rounded-box` 等）与主题变量。
4. 禁止引入 npm / Node 构建链。本项目前端编译**无 Node.js**，使用 Tailwind 独立可执行文件（见第 4、5 节）。
5. 编写 HTML 前**必须先加载 daisyui skill** 并按其中的组件规范写类名；组件类名拿不准时用 daisyui 文档 MCP（Context7：`mcp_daisyUI_Context7`）或官网 `daisyui.com` 查询，禁止凭记忆编造不存在的类。

## 3. 页面写法规范（Django 模板）

- 新页面一律继承母版，只需填 block：

```django
{% extends 'template.html' %}

{% block title %}页面标题（SEO）{% endblock %}
{% block keywords %}关键词{% endblock %}
{% block description %}页面描述{% endblock %}

{% block content %}
    <!-- 用 daisyUI + Tailwind 类名写页面主体 -->
    <div class="navbar bg-base-100 shadow-sm">
        <a class="btn btn-ghost text-xl">小影 API</a>
    </div>
    <div class="hero min-h-screen bg-base-200">
        <div class="hero-content text-center">
            <h1 class="text-5xl font-bold text-primary">你好，daisyUI</h1>
            <button class="btn btn-primary mt-4">开始使用</button>
        </div>
    </div>
{% endblock %}

{% block js %}
    <!-- 页面局部 JS（如需） -->
{% endblock %}
```

- 公共区块写进 `common_html/` 下的 include 文件，母版已 `include` `headers.html` / `footer.html`。
- **页头（`common_html/headers.html`）布局约定**：三段分别是 `.navbar-start w-auto shrink-0`（品牌，定宽不压缩）、`.navbar-center min-w-0 flex-1`（导航，占剩余空间、空间不足时横向滚动）、`.navbar-end w-auto shrink-0`（右侧控件组，永不压缩）。
  daisyUI 默认把 `navbar-start` / `navbar-end` 定宽 50%，**往右侧加新入口时不要去掉 `shrink-0`**，否则在英文 / 繁体等长文案下控件会被压变形并顶出页头（历史问题）。
- 主题切换：在 `<html>` 上设置 `data-theme="light|dark|..."`（内置主题在 `input.css` 的 daisyUI 插件中启用）。
- 交互组件（下拉、弹窗、折叠、主题切换等）优先用原生 `<details>` / `<dialog>` + daisyUI 类实现，需要少量 JS 时放进对应页面的 `{% block js %}`，**不引入 Vue / React / jQuery 等前端框架**。

## 3.1 多语言（i18n）写法规范

本项目由 Django i18n 驱动多语言，**源语言是简体中文**（`zh-hans`），另支持 `zh-hant`（繁体）/ `en`（英文）。

**模板文案：**

- 模板顶部必须有 `{% load i18n %}`，且**必须放在 `{% extends %}` 之后**（写在前面会报 `{% extends %} must be the first tag`）。
- 固定文案用 `{% trans "中文" %}`；含变量用 `{% blocktrans %}`：

```django
{% extends 'template.html' %}
{% load i18n %}

{% block title %}{% trans "接口文档中心" %}{% endblock %}
{% block keywords %}{% trans "接口文档,在线调试" %}{% endblock %}
{% block description %}{% trans "小影API 接口文档中心，支持在线调试。" %}{% endblock %}

{% block content %}
    <h1>{% trans "接口文档中心" %}</h1>
    {% blocktrans with name=service.name %}服务 {{ name }} 的文档{% endblocktrans %}
{% endblock %}
```

- `<title>` / `keywords` / `description` 等 SEO 文案同样要加 `{% trans %}`，不要漏。
- `{# … #}` 注释**只能写一行**，跨行会**原样渲染成页面文本**并把布局撑坏；多行注释请用 `{% comment %}…{% endcomment %}`。

**前端 JS 文案：**

- 用 `gettext('中文')`；含插值用 `interpolate(gettext('…%(x)s…'), {x: v}, true)`：

```javascript
const msg = gettext('请求失败');
const tip = interpolate(gettext('第 %(n)s 项'), { n: 1 }, true);
```

- 词典由 `/jsi18n/` 下发，**必须早于所有站点脚本加载**（母版已按此顺序加好，**勿删**）。
- JS 词条写进 `djangojs.po`，**不要**写进 `django.po`。

**新增文案后的流程：**

1. 补英文词条（`locale/en/LC_MESSAGES/django.po` 或 `djangojs.po`）；
2. 执行 `python scripts/make_zh_hant.py` 生成繁体词条；
3. 执行 `python scripts/compile_locale.py` 编译 `.mo`；
4. 完全重启 uWSGI（模板与翻译目录会被缓存，仅 `--reload` 不生效）。

> **不要翻译**：品牌名 `小影API`（logo）、URL、字段名、代码标识符。
> 详细流程见 `locale/多语言开发指南.md`。

## 4. 改完样式必须重编译（否则线上不生效）

Tailwind v4 只把"出现过的类"编译进 `output.css`。新增任何 daisyUI / Tailwind 类名后，必须**重新编译并提交 output.css**（线上 `collectstatic` 依赖它）：

```powershell
# Windows（在项目根目录执行）—— 单次编译
.\API\static\css\tailwindcss.exe -i API/static/css/input.css -o API/static/css/output.css

# 开发期常驻监听（改 input.css 或模板类名自动重编译）
.\API\static\css\tailwindcss.exe -i API/static/css/input.css -o API/static/css/output.css --watch
```

```bash
# Linux / macOS（部署机 / 生产）—— 单次编译
API/static/css/tailwindcss -i API/static/css/input.css -o API/static/css/output.css

# 开发期常驻监听
API/static/css/tailwindcss -i API/static/css/input.css -o API/static/css/output.css --watch
```

> 编译工具缺失时按第 5.1 节重新下载即可；`daisyui.mjs` / `daisyui-theme.mjs` 已随项目提交，无需重复下载。

## 5. daisyUI 环境自检与自动安装（新机器 / 产物缺失必读）

> **AI 强制流程**：进入前端任务时按 5.0 判定 → 缺什么补什么（5.1-5.5）→ 编译出 `output.css`（5.3）→ 通过 5.6 校验 → **然后才允许修改模板**。
> 全部命令均在**项目根目录**执行；安装属环境补齐操作，可直接执行，无需再次征询用户。

### 5.0 缺失判定（自检清单）

先列出目录并逐项核对（任一缺失即按对应小节补齐）：

```powershell
Get-ChildItem API/static/css        # Windows
```

```bash
ls API/static/css                   # Linux / macOS
```

| 产物 | 作用 | 缺失后果 | 补齐位置 |
| --- | --- | --- | --- |
| `tailwindcss.exe` / `tailwindcss` | Tailwind 编译器（约 107MB，未入库） | **无法编译**；新克隆 / 新机器必装 | 5.1 |
| `input.css` | 样式源码入口 | 无法编译，页面无样式 | 5.2 |
| `daisyui.mjs` | daisyUI 插件本体（已入库） | 编译报错、daisyUI 类名全部失效 | 5.1 |
| `daisyui-theme.mjs` | 主题插件（已入库） | `input.css` 的 `@plugin` 解析失败 | 5.1 |
| `output.css` | 页面唯一引用的编译产物 | **页面完全无样式** | 5.3 |
| `.trae/skills/daisyui/SKILL.md` | agent skill（组件规范） | AI 写 HTML 时无规范可依、易编造类名 | 5.5 |

> 判定技巧：`output.css` 首行应为 `/*! tailwindcss v4.x.x | ... */`；若为空或缺失，说明从未编译或编译失败。

### 5.1 补齐编译工具（手动下载，**推荐方式**）

以下地址均取自 daisyUI 官方安装文档（下载 latest 版本，不覆盖任何项目定制文件）：

```powershell
# Windows / PowerShell
curl.exe -sL -o API/static/css/tailwindcss.exe "https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-windows-x64.exe"

# daisyUI bundle（已入库；仅在缺失时为恢复用）
curl.exe -sL -o API/static/css/daisyui.mjs "https://github.com/saadeghi/daisyui/releases/latest/download/daisyui.mjs"
curl.exe -sL -o API/static/css/daisyui-theme.mjs "https://github.com/saadeghi/daisyui/releases/latest/download/daisyui-theme.mjs"
```

```bash
# Linux / macOS（按 CPU 架构选一条下载编译器）
curl -sLo API/static/css/tailwindcss https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-linux-x64
curl -sLo API/static/css/tailwindcss https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-linux-arm64
curl -sLo API/static/css/tailwindcss https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-macos-x64
curl -sLo API/static/css/tailwindcss https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-macos-arm64

# Linux / macOS 必须补可执行权限
chmod +x API/static/css/tailwindcss

# daisyUI bundle（已入库；仅在缺失时为恢复用）
curl -sLo API/static/css/daisyui.mjs https://github.com/saadeghi/daisyui/releases/latest/download/daisyui.mjs
curl -sLo API/static/css/daisyui-theme.mjs https://github.com/saadeghi/daisyui/releases/latest/download/daisyui-theme.mjs
```

> `daisyui.mjs` / `daisyui-theme.mjs` **已随代码入库**，正常克隆后无需下载；只有文件缺失或被误删时才需要。
> 下载后可校验可执行文件可用性：`tailwindcss.exe --help`（Linux/macOS：`API/static/css/tailwindcss --help`）应正常输出版本信息。

### 5.2 补齐 / 核对 `input.css`

`input.css` **已入库**，正常情况无需重建。若缺失，按下述内容新建（**注意保留本项目定制 `themes: all`**，不要照抄官方默认的 `@plugin "daisyui";`）：

```css
@import "tailwindcss";

@source not "./tailwindcss";
@source not "./daisyui{,*}.mjs";

/* 启用全部 daisyUI 内置主题（light/dark/…，供页头“主题”下拉切换）
   只想要少量主题时改成：themes: light --default, dark --prefersdark, cupcake; */
@plugin "./daisyui.mjs" {
  themes: all;
}

/* 可选：加载/自定义主题（空体=使用内置全部主题；自定义主题写法见 https://daisyui.com/docs/themes/ ） */
@plugin "./daisyui-theme.mjs"{
  /* 在此处编写自定义主题 */
}
```

> 说明：`@source not` 两行用于**排除编译工具自身**，避免 Tailwind 扫描 107MB 的可执行文件 / bundle 导致编译异常缓慢。

### 5.3 首次编译生成 `output.css`

补齐工具后必须编译一次，产物才是页面真正引用的样式：

```powershell
# Windows
.\API\static\css\tailwindcss.exe -i API/static/css/input.css -o API/static/css/output.css
```

```bash
# Linux / macOS
API/static/css/tailwindcss -i API/static/css/input.css -o API/static/css/output.css
```

> 产物 `output.css` **随代码入库**，因此线上部署时通常无需重新生成；只有新增 / 修改类名或改动 `input.css` 时才需重编译并提交（见第 4 节）。

### 5.4 兜底：官方 Fast install（注意：会覆盖 `input.css`）

官方提供一键脚本，会**下载编译器 + daisyUI bundle、重建 `input.css` 与 `output.css`**。因为会覆盖本项目 `input.css` 的 `themes: all` 定制，**仅在第 5.1 / 5.2 手动方式不可行时使用**：

```powershell
# Windows / PowerShell
cd API/static/css; powershell -c "irm daisyui.com/fast.ps1 | iex"
```

```bash
# Linux / macOS
cd API/static/css && curl -sL daisyui.com/fast | bash
```

使用前 / 后必做：

1. 执行前备份：`copy API\static\css\input.css API\static\css\input.css.bak`（Linux/macOS 用 `cp`）；
2. 执行后**恢复定制**：确认 `input.css` 中 daisyUI 插件为 `@plugin "./daisyui.mjs" { themes: all; }`，并保留 `@plugin "./daisyui-theme.mjs"`；
3. 重新编译（第 5.3 节）并删除备份文件。

> 官方 Fast install 文档：<https://daisyui.com/docs/install/django/>

## 6. 常用 daisyUI 类速查（更多以 skill / 官方文档为准）

- 按钮：`btn` `btn-primary|secondary|accent|ghost|outline|soft|dash` `btn-sm|md|lg|xl` `btn-circle` `btn-block`
- 布局/导航：`navbar` `menu` `dropdown` `drawer` `footer` `breadcrumbs` `tabs` `steps` `mockup-*`
- 内容：`card`（`card-body` `card-title` `card-actions`）、`hero`、`alert`、`badge`、`stat`、`timeline`
- 表单：`input` `input-bordered|ghost|soft` `textarea` `select` `checkbox` `toggle` `radio` `range` `label` `fieldset`（表单类名加在组件上，不再需要其它 UI 库）
- 反馈/交互：`modal`（配合 `<dialog>`）、`collapse`、`toast`、`loading`、`tooltip`
- 排版/配色：`text-primary|base-content`、`bg-base-100|200|300`、`border-base-300`、`prose`（需额外插件时可咨询后决定）
